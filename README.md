# Overview

This data and code repository is supplemental to the manuscript "Tegula funebralis populations possess distinct aperture morphologies corresponding to an energy and predation gradient, "


Ice age refugium shows potential for geohistorical data to guide modern conservation efforts" currently under review at Communications Earth & Environment. All data files were pulled from the Neotoma database using scripts contained herein. Geochronologic controls were pulled on January 12, 2025, and pollen data were last pulled on January 1, 2026.

All code is self-contained and does not require additional materials from outside of this repository.
